# URL Shortener

## Objective
Build a simple service that takes a long URL and generates a short, unique alias.

## Requirements
- Input field for the long URL.
- Generate a 6-character unique code.
- Store the mapping in memory or a simple database.
- Redirect the short URL to the original long URL.

## Tech Stack
- Frontend: React / Next.js
- Backend: Node.js / Express or Next.js API Routes
- Database: Supabase or simple JSON file

## Difficulty
Level: Easy
Time: 2-4 Hours
