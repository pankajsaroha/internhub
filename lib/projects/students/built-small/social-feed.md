# Social Media Feed (Clone)

## Objective
Build a simplified version of a social media feed like Instagram or Twitter.

## Requirements
- Create and display posts (text + images).
- Like and Comment functionality.
- User profile view.
- Real-time updates (optional).

## Tech Stack
- Next.js
- Supabase (Database + Auth)
- Cloudinary (for Image uploads)

## Difficulty
Level: Advanced
Time: 12-16 Hours
