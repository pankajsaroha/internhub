# SaaS Dashboard Template

## Objective
Build a complex admin dashboard for a SaaS product.

## Requirements
- Data visualization using charts (Recharts/Chart.js).
- User management tables with filtering and sorting.
- Sidebar navigation and header.
- Dark/Light mode toggle.

## Tech Stack
- Next.js (App Router)
- Lucide Icons
- Recharts

## Difficulty
Level: Advanced
Time: 10-14 Hours
