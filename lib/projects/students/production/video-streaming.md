# High-Performance Video Streaming Service

## Objective
Build a video streaming platform that handles large files and concurrent users efficiently.

## Requirements
- Video transcoding (using FFmpeg).
- HLS/DASH streaming support.
- CDN integration for content delivery.
- User analytics and watch history.

## Tech Stack
- Next.js
- AWS S3 / CloudFront
- Mux or custom FFmpeg worker
- Redis for caching

## Difficulty
Level: Production
Time: 50-70 Hours
