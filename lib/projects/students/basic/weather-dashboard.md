# Weather Dashboard

## Objective
Build a weather application that fetches real-time data from a public API.

## Requirements
- Search by city name.
- Display current temperature, humidity, and wind speed.
- Show a 5-day forecast.
- Use `fetch` or `axios` for API calls.

## Tech Stack
- React / Next.js
- OpenWeatherMap API

## Difficulty
Level: Intermediate
Time: 4-6 Hours
