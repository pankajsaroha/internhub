# E-commerce Product Page

## Objective
Create a responsive product detail page with a shopping cart flow.

## Requirements
- Dynamic product data rendering.
- Add to cart functionality with state management.
- Responsive image gallery.
- Review and rating section.

## Tech Stack
- React / Next.js
- Tailwind CSS (Optional) or CSS Modules
- Context API/Redux for Cart State

## Difficulty
Level: Intermediate
Time: 6-8 Hours
