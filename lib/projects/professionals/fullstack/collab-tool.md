# Real-time Collaboration Tool

## Objective
Build a shared whiteboard or document editor.

## Requirements
- Multiple users can edit simultaneously.
- Operational Transformation (OT) or CRDTs for conflict resolution.
- Presence indicators (who is online).

## Tech Stack
- Next.js
- WebSocket / Socket.io
- Redis (for pub/sub)

## Difficulty
Level: Expert
Time: 25-35 Hours
